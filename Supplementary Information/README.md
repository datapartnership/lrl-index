# Supplementary Information

This folder holds context and reference documents that sit outside the individual tier/harvest folders, but are useful for understanding the project as a whole — especially for anyone picking up this work who wasn't involved in building it. Where the tier-specific READMEs and methodology docs explain *how* each piece works, these documents explain the *why*, the *what's left to do*, and *who to ask* if something isn't clear.

## Documents

| Document | What it's about |
|---|---|
| `Index Overview.docx` | A high-level overview of the LRL Index — what it measures, why it exists, and how it's structured. |
| `Next Steps.docx` | Outstanding work across every part of the project (population data, Tier A/B/C, audio harvest, data threshold gates, and building the final index), with concrete next actions for each. |
| `Challenges.docx` | Major challenges encountered so far, organized by section, each written up as a problem/solution pair. |
| `Contact Information.docx` | Who to reach out to for questions about different parts of the project. |
| `language-data-index-intern-workplan.docx` | The original intern workplan this project was built against — weekly deliverables and goals from the start of the internship. |
