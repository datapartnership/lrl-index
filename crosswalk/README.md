# Crosswalk

Joins the full ISO 639-3 language standard against three AI training data sources: FineWeb-2 (web text), Hugging Face Hub (dataset tags), and Mozilla Common Voice (transcribed audio).

This is the Week 2 deliverable for the project's code crosswalk + curated language list work. It is not filtered to the project's curated language list — it covers all ~7,929 ISO 639-3 languages, so it can be reused as the project's scope expands or changes.

## Team decision on unmatched languages

As of June 2026, the team has decided to leave all non-matches as-is. No substitution, patching, or resolution logic is applied. A language that doesn't match a given source is recorded as `match_status = "no_match"` and left there — final, not pending.

This follows from three recurring mismatch cases identified during development (full detail in `docs/LRL Crosswalk Methodology.docx`):

- Macrolanguage tracked, source only has one specific member (e.g. Akan vs. Twi)
- Regional dialect tracked, source only has the standard/umbrella variety (e.g. Ta'izzi-Adeni Arabic vs. Standard Arabic)
- Reverse of the above — source has macrolanguage-level data, we track a specific individual language (e.g. Common Voice's general Chinese locales vs. Mandarin)

## Scripts (run in order)

| Script | What it does |
|---|---|
| `step1_load_iso_table.py` | Loads the full ISO 639-3 table from SIL, derives `is_macrolanguage` / `is_living` flags |
| `step2_fetch_fineweb2_labels.py` | Fetches FineWeb-2's language-script labels via the Hugging Face datasets-server API |
| `step3_join_fineweb2.py` | Joins FineWeb-2's language-script labels onto the ISO table |
| `step4_fetch_huggingface_tags.py` | Fetches Hugging Face Hub's full language tag vocabulary |
| `step5_join_huggingface.py` | Joins Hugging Face Hub's language tags. Records both ISO 639-3 and BCP-47 tags when both exist (e.g. `swh;sw`) |
| `step6_fetch_commonvoice_langs.py` | Fetches Mozilla Common Voice's language stats |
| `step7_join_commonvoice.py` | Joins Common Voice's locale codes. Records all matched locales when multiple regional variants exist (e.g. `zh-CN;zh-TW;zh-HK`) |
| `step8_summary_report.py` | Coverage statistics across all 3 sources, exported as CSVs |
| `step9_find_unmapped_source_codes.py` | Reverse check — codes/labels in a source with no ISO 639-3 home at all, flagged with macrolanguage-family info via `langcodes` |
| `build_macrolanguage_members.py` | Full macrolanguage → all-members lookup, from SIL's separate Macrolanguage Mappings table |

## Required raw inputs

Place in `data/raw/` before running (see `data/raw/README.md` for download links — not committed, since three are live API snapshots that go stale):

- `iso-639-3.tab`
- `iso-639-3-macrolanguages.tab`
- `fineweb2_labels.txt` — generated by `step2_fetch_fineweb2_labels.py`
- `hf_language_tags.json` — generated by `step4_fetch_huggingface_tags.py`
- `commonvoice_languages_raw.json` — generated by `step6_fetch_commonvoice_langs.py`
